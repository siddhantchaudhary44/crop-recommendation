# Crop Recommendation System

A Machine Learning-based Crop Recommendation API that predicts a suitable crop using soil nutrients and environmental conditions.

## Features
- 22 Crop Classes
- Voting Classifier Ensemble
- FastAPI Backend
- Google Cloud Storage for Model and Scaler
- Docker Containerization
- Deployment on Google Cloud Run

## Input Features
- Nitrogen
- Phosphorus
- Potassium
- Temperature
- Humidity
- pH_Value
- Rainfall

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, FastAPI, Docker, Google Cloud Storage, Google Cloud Run
